Panel de administración

Acceso restringido. Pega tu token de acceso de GitHub — se guarda solo en este dispositivo y nunca sale de tu navegador.

¿Cómo saco mi token?
  1. En GitHub: foto de perfil → Settings → hasta abajo, Developer settings.
  2. Personal access tokens → Fine-grained tokens → Generate new token.
  3. En Repository access elige Only select repositories y marca el repositorio del catálogo.
  4. En Permissions → Repository permissions, pon Contents en Read and write.
  5. Genera el token, cópialo y pégalo aquí. GitHub solo te lo muestra una vez.

Falta conectar la base de datos

Abre assets/js/config.js y cambia github.usuario por tu nombre de usuario de GitHub, y github.repo por el nombre del repositorio. Los pasos están en el README.
